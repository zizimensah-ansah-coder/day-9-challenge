This project is a task management dashboard , which helps users to add a task, it's id and it's status .It also helps to view the task. 
The project is being run using dev Tools such as Chrome ,but with this i used Chrome
Some API / features used includes GET , which is used to fetch tasks from the jsonplaceholder.typicode.com, POST used to create a task
I also used the async/await to wait for responses , try catch() to handle errors
